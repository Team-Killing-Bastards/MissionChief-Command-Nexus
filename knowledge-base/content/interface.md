## What this does

**Nexus Tools** contains data views, profiles and settings. Mission controls select and dispatch units. Unit Naming, Station Naming and Personnel Assignment are separate administration panels.

## Prerequisites

A signed-in supported game page with one active Nexus installation.

## Step by step

1. Open the game's Help menu and choose **Nexus Tools**.
2. Start with **Overview** for shortcuts, account sync and **What's changed**.
3. Choose **Buildings**, **Vehicles** or **Schooling** for an on-demand view.
4. Use search and filters, then **Refresh** for a fresh snapshot.
5. Choose **Profiles** for station targets or **Settings** for preferences.
6. Open a mission for Unit Finder, Mission Update and dispatch.
7. Read the personal mission controller separately from the Alliance panel.

## Expected result

You can find the appropriate work area without starting automation or changing the game.

## Warnings

> A data view is a snapshot, not proof of current dispatch availability.

## Troubleshooting

Refresh the game after enabling Nexus. Close/reopen Tools for a stale view. Return to the main game page if a control is missing on a transport or worker page; those pages deliberately expose a different operational surface.
