## What this does

Alliance support adds its own panel and optional batch automation. Sharing controls can share an open mission with an optional note and combine sharing with dispatch.

## Prerequisites

Join the intended alliance, confirm permission and keep enough fleet capacity for personal missions. Prove manual selection first.

## Step by step

1. Open **Nexus Tools → Settings**.
2. Enable **Alliance mission support panel** if needed.
3. Review **Minimum mission credits (0 = all values)**.
4. Set **Missions per automatic batch** and **Pause between batches (minutes)**.
5. Keep **Run Alliance Auto in the background** off while reviewing.
6. Select **Save settings** and inspect the panel.
7. Enable background Alliance Auto only when scope is correct; watch a small first batch.
8. Disable that setting and save when stopping alliance processing.

## Expected result

Panel and batch status reflect the saved choices. Local defaults are 10 missions, a ten-minute pause and background Alliance Auto off.

## Warnings

> Alliance dispatch consumes live fleet capacity. **Share + dispatch** dispatches units already selected. Posting a note to alliance chat is a separate option to inspect before submitting.

## Troubleshooting

Check panel preference and credit filter if no missions appear. Check Alliance Auto if work continues after personal Auto Mode stops. After an uncertain sharing result, inspect the mission and en-route units before repeating it.
