## What this does

The manifest and settings expose map, schooling, financial, display and transport tools. This is an orientation; task-specific live walkthroughs are incomplete.

## Prerequisites

Use the relevant game page, confirm your build and stop automation before dispatch-related changes.

## Step by step

1. Open **Nexus Tools → Settings**.
2. Find the relevant group.
3. Change one preference and select **Save settings**.
4. Reopen the page when the settings screen says changes apply on page load.
5. Verify the visible result before another change.

**Screenshot pending:** A current capture of this screen is still required. No generated substitute is included.

## Available surfaces

- **Mission list:** Compact cards, estimated credits, treatment time and fixed navigation.
- **Mission window:** Generation time, older-mission highlighting, missing requirements, selection buttons, incoming/selected ticks, groups and crew summaries.
- **Schooling:** Course/personnel filters and **Educate and open the next course**.
- **Buildings/personnel:** Extension cards, training summaries, assigned counts and assignment shortcuts.
- **Credits/coins:** Dropdown, daily summary and history chart on their respective game pages.
- **Map:** Realism setup/location and staging modules exist. Hospital bed numbers have a separate preference.
- **Transport:** **Open the first transport request** and **Jump to the next request after finishing**.
- **Event Scanner:** **Automatically collect mission event items** in local .235.
- **Reporting:** Private collector controls and mission diagnostic export.

## Expected result

The chosen feature appears on its relevant page. A display toggle does not train staff, purchase a building extension or establish dispatch readiness.

## Warnings

> Schooling, purchases, profile application and building deletion can change game records. Module existence is not an instruction to run them in bulk.

Live Realism setup, staging, map labels, schooling actions and financial walkthroughs are still required before this can be called an exhaustive manual.

## Troubleshooting

Check the toggle, page, installed build and apply-on-reopen behaviour. Missing geographic data does not prove the real-world facility is absent.
