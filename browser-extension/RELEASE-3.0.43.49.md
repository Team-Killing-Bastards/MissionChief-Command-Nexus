# Nexus 3.0.43.49 — local schooling update

Course name is now a dropdown of distinct active course names in the selected course type, drawn from both native course lists. Selecting a different type resets the name selection. Duplicate advertised sessions share one name option and remain separate rows. An ended selected course shows no matches and an unavailable option until that course returns; it never silently broadens the filter. Native sorting, search, links and countdowns remain intact.

**Open courses** appears beside **Refresh crew & training** in the specialist crew panel. It opens the native course list with **All station training** selected and, where the matching courses share one type, that course type selected too. Known aliases match personnel labels such as HazMat Unit to course labels such as HazMat. The dropdown can narrow the results to one course. If none of the requested courses is active, the result stays empty. Clear filters removes the shortcut. The URL fragment contains only the displayed training names and aliases, without station, account or personnel identifiers; this feature makes no extra requests.

On an advertised course's personnel-selection page, **Educate** uses Nexus styling. **Educate + select again** clicks the original native Educate button once, preserving validation, handlers, submitter fields and native POST behaviour. After the game supplies an enrolment success notice, Nexus returns to the same advertised course with a GET, no staff selected, and the dispatch-centre/station filters restored. It does not create another course or retry enrolment. Full-course and error results remain visible. If success cannot be confirmed, the result remains visible with a manual return link. The pending return is tab-session state lasting at most two minutes. Native submissions cancelled by the game do not arm a return. The feature is scoped to native advertised-course forms; it does not alter school-owned course creation.

Settings > Schooling contains **Course type and name filters**, **Course personnel filters**, and the new **Educate and select another batch** switch. Refresh after changing these. The course-list switch also controls the crew shortcut.
