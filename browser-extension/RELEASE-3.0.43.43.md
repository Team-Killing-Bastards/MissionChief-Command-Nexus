# MissionChief Command Nexus 3.0.43.43

Promotes the user-tested local .43 build to both existing Store listings. The
runtime is copied byte-for-byte from that tested build; the release does not
regenerate the older .21 dispatch implementation.

- Central Nexus Tools Settings with 36 on/off switches, mission controls,
  Event Scanner, transport preferences and reporting shortcuts.
- Overview, Buildings, Vehicles, Schooling and Settings tabs; Mission-only
  mission overlay; top-right Tools launcher and a 440px desktop Naming tool.
- Native credits/coins menu, daily summaries, credit history charts and
  estimated mission-card rewards without the full LSS runtime.
- Native vehicle groups, dispatch/share controls, transport navigation,
  personnel summaries, training filters and building extension cards.
- Partial specialist crew coverage shows an orange warning; recovery and
  flatbed capacity contribute to Cars to tow coverage.
- Includes the previously tested local performance and memory changes through
  .42. No additional dispatch or speed changes are introduced during promotion.

Permissions and game origins remain unchanged. Only the bundled Nexus icon is
web-accessible, restricted to the two supported MissionChief UK origins. The
existing opt-in reporting, private queue storage and production destination
configuration remain in place. Adapted LSS reference data retains its licence
and attribution in the package.

`reference/local-43.json` records the source ZIP and all tested file hashes.
Permitted Store transformations are the extension name, Tools version label,
production endpoint injection and omission of local-only installation text.
The publication jobs consume the same verified ZIP and record independent
submission receipts. Submission does not establish review approval or rollout.
