# Team Killing Bastards Organisation Profile Blueprint

The completed organisation homepage is stored at:

```text
organisation-profile/profile/README.md
```

GitHub displays an organisation profile only when that file exists at `profile/README.md` inside a **public repository named `.github`** owned by the organisation.

## Deployment target

```text
Team-Killing-Bastards/.github
└── profile
    └── README.md
```

The profile is already written and can be copied unchanged once the special repository exists.

## Current limitation

The connected GitHub integration can edit repositories to which it has been granted access, but it cannot create a new organisation repository or change organisation-level profile settings. This blueprint prevents that limitation from delaying the design work.
