# Discord & sync

## 1.1.0 — atomic personnel-register replacement

Adds a reviewed replacement operation with account/player scope, atomic server commit, read-back verification, persistent operation receipts and register generations for other browsers. Settings and profiles are excluded. Requires the matching VPS update and .265 on receiving browsers. See [3.0.43.265](../extension-changelog.md#v3-0-43-265-replace-cloud-register).
